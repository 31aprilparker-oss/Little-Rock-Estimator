Little Rock Construction Estimator PWA v1

Deploy all four files to an HTTPS web host:
index.html
manifest.webmanifest
sw.js
icon.svg

Then open the site on iPhone or Android and use Add to Home Screen / Install.
Project inputs, openings, prices and labor rates are saved locally on the device.

This is a first working prototype. It does not yet include cloud accounts,
multi-user synchronization, live supplier pricing, or native App Store packaging.
Verify plans, specifications, assemblies, rates and supplier quotes before issuing
a contractual bid.
